# X(트위터) 좋아요 링크 수집 & 일괄 해제

`x.com/<내아이디>/likes` 페이지에 작은 패널을 띄워서:

1. **링크 수집**: 자동으로 스크롤하며 좋아요한 게시물 링크를 모두 모읍니다 → TXT / CSV / JSON 다운로드, 클립보드 복사
2. **좋아요 모두 해제**: 버튼 한 번으로 위에서부터 차례로 좋아요를 해제합니다 (해제 직전에 링크를 자동 저장)

## 로그인 필요한가요?

**네, 필요합니다.** 2024년 6월부터 X의 좋아요 목록은 비공개라서 본인만 볼 수 있습니다.
다만 이 도구는 **이미 로그인된 내 브라우저 안에서** 화면을 읽고 버튼을 눌러주는 방식이라:

- 비밀번호나 API 키를 입력할 필요가 없습니다
- 외부 서버로 아무것도 전송하지 않습니다 (수집 결과는 내 브라우저 localStorage에만 저장)
- 유료 X API(Basic 플랜 등)가 필요 없습니다

## 설치 & 사용

### 방법 A: Tampermonkey (추천)

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/) 확장 설치
2. Tampermonkey 대시보드 → `+`(새 스크립트) → `x-likes-tool.user.js` 내용을 붙여넣고 저장
3. x.com에 로그인 → 프로필 → **좋아요** 탭 (`https://x.com/<내아이디>/likes`)
4. 오른쪽 아래 패널에서 **링크 수집** → 끝나면 **TXT / CSV / JSON**으로 저장
5. 필요하면 **좋아요 모두 해제**

### 방법 B: 콘솔에 붙여넣기 (설치 없이 1회용)

1. `https://x.com/<내아이디>/likes` 열기
2. `F12` → Console 탭
3. `x-likes-tool.user.js` 내용 전체를 붙여넣고 Enter
   (Chrome이 붙여넣기를 막으면 콘솔에 `allow pasting` 을 먼저 입력)

## 출력 형식

- **TXT**: 한 줄에 링크 하나 (`https://x.com/작성자/status/123...`)
- **CSV** (엑셀에서 바로 열림): `url, author, tweet_time, text, unliked, collected_at`
- **JSON**: 위와 같은 필드의 배열

## 주의사항

- **해제는 되돌릴 수 없습니다.** 먼저 링크를 다운로드해 두세요.
- X에는 요청 제한(rate limit)이 있어서 1.2~2.5초 간격으로 천천히 해제하고, 50개마다 30초 쉽니다.
  연속으로 실패하면 자동으로 멈추니 15분~몇 시간 뒤 다시 실행하세요. 속도는 스크립트 상단 `CFG`에서 조절할 수 있습니다.
- X 웹 화면은 아주 오래된 좋아요를 끝까지 보여주지 않는 경우가 있습니다.
  다 해제했는데 남은 게 있다면 새로고침 후 다시 실행해 보세요.
  전체 목록이 꼭 필요하면 **설정 → 내 계정 → 데이터 아카이브 다운로드**의 `like.js`에 모든 좋아요의 게시물 ID가 들어 있습니다.
- 자동화 도구 사용은 X 이용약관상 회색지대입니다. 본인 계정에 대해서, 적당한 속도로만 사용하세요.
- X가 화면 구조(`data-testid`)를 바꾸면 동작하지 않을 수 있습니다.
