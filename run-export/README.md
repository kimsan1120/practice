# 러닝 기록 내보내기 (RunExport)

갤럭시 워치 → 삼성 헬스 → **Health Connect** 에 저장된 운동 기록을 날짜별로 골라서
CSV / GPX 파일로 내보내는 안드로이드 앱입니다.

```
갤럭시 워치 5 ──동기화──▶ 삼성 헬스 ──동기화──▶ Health Connect ──읽기──▶ 이 앱 ──▶ CSV / GPX
```

## 할 수 있는 것

- 날짜 선택(◀ ▶, 오늘) → 그날의 **러닝만** (또는 모든 운동) 목록
- 기록을 누르면 상세 화면:

| 화면 | 내용 |
|---|---|
| 운동 상세정보 | 운동/총 시간, 거리, 칼로리, 걸음, 평균·최고 페이스, 평균·최고 속도, 평균·최대 심박, 평균·최대 케이던스, 누적 상승·하강, 최저·최고 고도, 오르막·내리막 거리, VO2max(+등급) |
| 경로 | GPS 경로 모양 (출발/도착, 가장 빠른 1km 빨간색) |
| 차트 | 페이스 / 심박 / 케이던스 / 고도 (가장 빠른 1km 음영) |
| 구간기록 | 1km 구간 시간·페이스·심박, ★ 가장 빠른 구간, 워치 랩 |
| 심박수 구간 | 최대 심박 기준 5구간 시간·비율, 역치(직접 입력) 기준 3구간 |
| 회복 심박 | 종료 시 → 1분 후 → 2분 후 심박과 하락폭, 곡선 |
| VO2max | 값, 등급(출생연도·성별 입력 시), 최근 180일 추이 |
| 컨디션 · 메모 | 체감 난이도 1~10, 메모, 아침 안정시 심박, 체중, **운동 시각 기온**(버튼) |
| 데이터 진단 | 삼성 헬스가 Health Connect 에 실제로 넘긴 항목과 개수 |

- **통계** (오른쪽 위 달력 아이콘): 주간·월간 거리 막대, 월 목표 진행률, 페이스·심박·효율 추이,
  **개인 최고 기록**(1km·3km·5km·10km·하프), 기간 CSV 내보내기
- **베스트 구간 · 효율 · 부하**: 기록 안의 가장 빠른 1/3/5/10km(🏅PB 표시), 효율 지수(EF),
  유산소 디커플링, 심박 드리프트, 훈련 부하(TRIMP)
- **지난 기록과 비교**: 비슷한 거리(±15%)의 가장 최근 러닝과 페이스·심박·효율 비교
- **새 러닝 알림** (설정에서 켜기): 15분마다 확인해서 새 러닝이 들어오면 알림, 누르면 바로 그 기록이 열림
- **분석용 텍스트 복사**: 상세정보 + 구간 + 심박 구간 + 회복 심박 + 컨디션을 한 번에 붙여넣기 좋은 글로 복사
- **파일 공유 / 다운로드 저장**: 분석 텍스트 + CSV + GPX

| 파일 | 내용 |
|---|---|
| `runs_YYYYMMDD_summary.csv` | 그날 기록들의 요약 (한 줄 = 운동 1회) |
| `run_..._analysis.txt` | 분석용 텍스트 (복사 버튼과 같은 내용) |
| `run_..._summary.csv` | 선택한 기록의 요약 |
| `run_..._splits.csv` | 1km 구간 기록 |
| `run_..._hr_zones.csv` | 심박 구간별 시간 |
| `run_..._samples.csv` | 시각별 심박 / 속도 / 페이스 / 케이던스 / 위도·경도·고도 |
| `run_..._laps.csv` | 워치 랩 기록 (있을 때만) |
| `vo2max_history.csv` | VO2max 추이 (있을 때만) |
| `run_....gpx` | GPS 경로 + 심박 (경로를 불러왔을 때만, Strava 업로드 가능) |

CSV 는 UTF-8(BOM) 이라 엑셀에서 바로 열어도 한글이 깨지지 않습니다.

### 설정 (오른쪽 위 '설정')

출생연도, 성별, 최대 심박, 유산소/무산소 역치 심박, 체중. 심박 구간과 VO2max 등급 계산에 씁니다.
GPS 경로를 기록마다 묻지 않으려면 Health Connect 설정 → 앱 권한 → 러닝 기록 내보내기 → 운동 경로 → **항상 허용**.

### 받을 수 없는 것

삼성 헬스가 Health Connect 로 넘기지 않아서 이 앱으로는 볼 수 없습니다:
**달리기 폼**(좌우 비대칭, 지면 접촉 시간, 체공 시간, 규칙성, 수직 진폭, 강성), 삼성의 역치 추정치,
땀 손실 추정치, 성취 배지.

## 설치 방법 (Android Studio 없이)

1. 이 저장소의 **Releases → `apk-latest`** 에서 `RunExport.apk` 를 휴대폰으로 다운로드
   (GitHub Actions 가 코드를 올릴 때마다 자동으로 빌드해서 올립니다.
   Actions 탭의 실행 결과 → Artifacts 에서도 받을 수 있어요.)
2. 다운로드한 파일을 누르고 "출처를 알 수 없는 앱 설치"를 허용 → 설치
3. 앱 실행 → **권한 허용하기** → 운동/심박/거리 등 모두 허용

> 버전 1.1 부터 서명 키가 고정돼서 **덮어쓰기 설치**가 돼요 (설정·메모 유지).
> 1.0 에서 1.1 로 올릴 때만 한 번 지우고 다시 설치하세요.
>
> 서명 키(`app/debug.keystore`)는 디버그용이라 저장소에 들어 있어요. 저장소가 공개라서 다른 사람도
> 같은 서명으로 APK 를 만들 수 있지만, 그 파일을 직접 설치하지 않는 한 영향은 없어요.
> 숨기고 싶으면 키를 GitHub Secret 으로 옮기면 됩니다.

## 휴대폰 사전 설정 (한 번만)

1. **삼성 헬스 → 설정(⋮) → Health Connect** → 삼성 헬스가 Health Connect 에
   **운동, 심박수, 거리, 속도, 걸음, 칼로리** 등을 *쓰도록(공유)* 허용
2. 러닝 후 워치 → 삼성 헬스 동기화가 끝났는지 확인 (삼성 헬스 앱에서 기록이 보이면 OK)
3. 삼성 헬스가 Health Connect 로 보내는 데 시간이 조금 걸릴 수 있어요. 앱에 안 보이면
   삼성 헬스를 한 번 열었다가 다시 와보세요.

## 알아둘 점

- Health Connect 에 넘어오는 항목만 읽을 수 있어요. 무엇이 넘어오는지는 상세 화면의 **데이터 진단** 에서 확인하세요.
- 기온은 버튼을 누를 때만 대략적인 위치(소수점 2자리, 약 1km)와 날짜를 Open-Meteo 에 보내 가져옵니다.
- 1km 구간은 GPS 경로 → 거리 기록 → 속도 기록 순으로 가능한 데이터로 계산하고,
  세션 총 거리에 맞춰 보정합니다. 구간 시간에는 일시정지가 포함될 수 있어요.
- 기본적으로 **권한을 처음 준 날 기준 30일 이전** 기록은 읽을 수 없어요.
  기기가 지원하면 앱이 "과거 데이터 읽기" 권한도 함께 요청합니다.
- 그 외 데이터는 휴대폰 밖으로 나가지 않아요. 설정·메모는 휴대폰 안에만 저장돼요.

## 직접 빌드

```bash
cd run-export
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 구간 계산 단위 테스트
```

JDK 17+, Android SDK (compileSdk 36) 필요. Android Studio 로 `run-export` 폴더를 열어도 됩니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `HealthRepository.kt` | Health Connect 읽기 (세션 목록, 집계, 심박/속도/거리/경로) |
| `SplitCalculator.kt` | 1km 구간 계산 |
| `Analysis.kt` | 최고 페이스, 고도·경사, 케이던스, 심박 구간, 회복 심박, VO2max 등급 |
| `Prefs.kt` / `Weather.kt` | 설정·메모·요약 캐시 저장 / 기온 가져오기 |
| `Stats.kt` / `StatsScreen.kt` | 주간·월간 통계, 개인 최고 기록, 비교 대상 찾기 / 통계 화면 |
| `NewRunWorker.kt` | 새 러닝 알림 (WorkManager + Health Connect 변경 내역) |
| `Theme.kt` | 색·글꼴·공통 카드 |
| `DetailScreen.kt` / `SettingsScreen.kt` / `Charts.kt` | 상세 화면 / 설정 / 차트·경로·구간 막대 |
| `Exporter.kt` | CSV / GPX 생성, 공유, 다운로드 저장 |
| `MainViewModel.kt` | 화면 상태 |
| `MainActivity.kt` | 화면 (Jetpack Compose) |
| `PermissionsRationaleActivity.kt` | Health Connect 권한 안내 화면 |
